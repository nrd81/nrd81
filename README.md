# Hi, I'm Nick 👋

**Operations manager → data analyst.** I spend my days migrating legacy Microsoft Access programs to Power BI, and my nights running a Proxmox homelab like it's production.

## What I'm working on

- 🔄 **Legacy modernization** — moving decades-old Access databases into Power BI: data modeling, DAX measures, Power Query (M) transformations, and the stakeholder conversations that make migrations stick
- 📊 **The analytics stack** — SQL, DAX, M, Power Automate, with Qlik and Databricks in the toolkit
- 🏠 **Homelab as a practice ground** — a 3-node Proxmox cluster, 20+ Docker services, ZFS storage, zero-trust ingress, all managed as code → [homelab-infra](https://github.com/nrd81/homelab-infra)
- 🤖 **AI-in-the-loop operations** — a GitOps pattern where an AI agent proposes infrastructure changes as pull requests and I approve them from my phone; a deterministic script does the applying

## How I work

Operations taught me things that transfer directly to data work: **diagnose before you fix, verify every change, make it repeatable, write it down.** Every incident in my homelab becomes a runbook. Every migration at work becomes a template.
